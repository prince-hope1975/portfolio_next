# Project visual sources

- `simplecx-studio.webp`: frame from the user's `simplecx-walkthru.mp4`, Content Studio at 01:45. Browser chrome and the address bar were removed; product UI colors and proportions were preserved.
- `simplecx-public.webp`: actual public homepage at https://simplecx.retink.io/, captured on 2026-10-09 after rejecting optional analytics.
- `drapon-input.webp`: DrapOn's local demo pipeline asset, `apps/web/public/demo/pipeline/dress/00_original.webp`.
- `drapon-cutout.webp`: DrapOn's local demo pipeline output, `apps/web/public/demo/pipeline/dress/09_cutout.webp`.

The DrapOn demo could serve its public shell but did not complete its session check during capture. The actual pipeline assets are used in its place. alswap's public domains did not resolve during capture; alswap and Atlas DAO therefore use explicitly labeled architecture illustrations, rather than invented interface screenshots.
